HR Analytics Dashboard | Power BI
Project Overview
This project is an HR Analytics Dashboard created using Microsoft Power BI. It is designed to explore workforce information and present HR-related metrics and patterns in interactive report pages.

The uploaded Power BI file is named PB+10.pbix.
Dashboard Focus
The report includes HR measures and analysis related to:
- Employee headcount
- Employee age and age groups
- Employee tenure
- Attrition rate
- Hiring rate and new hires
- Employee satisfaction
- Department and job-family information
- Education level
- Location and office-related attributes
- Overtime hours
- Performance, engagement, and work-life-balance scores

1. Download PB+10.pbix from this repository.
2. Open Microsoft Power BI Desktop.
3. Select File → Open and choose the downloaded .pbix file.
4. Explore the report pages, visuals, and filters.
